# Security policy

## Supported versions

| Version | Supported |
| ------- | --------- |
| Latest 1.x release | Yes |
| Older releases | No |

Please update to the [latest release](https://github.com/gajishere/surf-browser-releases/releases/latest) before reporting, in case the problem is already fixed.

## Report a vulnerability

Report privately through GitHub:

<https://github.com/gajishere/surf-browser-releases/security/advisories/new>

Do not report security problems in a public issue, discussion or pull request.

Please include:

- The Surf version (type `ver` in Surf) and your Windows version.
- A description of the problem and its impact.
- Steps to reproduce, or a proof of concept.
- Any suggested fix, if you have one.

## What to expect

We aim to reply within 7 days. After that we will keep you updated as we investigate, and credit you in the release notes if you would like that. Please give us a reasonable chance to fix the problem before you disclose it publicly.

## Scope

In scope:

- Surf itself.
- Its built-in pages.
- Its handling of downloads.
- Its bundled ad blocker update check.

Out of scope:

- Bugs in the Microsoft Edge WebView2 runtime itself. Report these to Microsoft: <https://msrc.microsoft.com/report>.
- Bugs in websites.
